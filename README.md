## Sobre Este Repositório

Portfólio completo dos projetos desenvolvidos no primeiro semestre, demonstrando habilidades em **programação**, **banco de dados** e **desenvolvimento web**.

---

## Projetos

### 📊 Algoritmos e Pensamento Computacional

**Calculadora Científica**  
Calculadora com 36 operações matemáticas avançadas desenvolvida em C.

**Média de Notas**  
Sistema de gerenciamento de alunos com cálculo de média e alocação dinâmica.

**Ordenação**  
Implementação de algoritmos de ordenação em C.

---

### 🗄️ BD-Modelagem

**Cidade Inteligente**  
Sistema completo de modelagem de banco de dados educacional utilizando pgAdmin 4.  


**Etapas do Projeto:**
- Modelo Conceitual
- Projeto Lógico
- Modelo Físico
- Dicionário de Dados

---

### 🎨 FrontEnd

**Bebidas Imaginárias**  
Site responsivo de cardápio com mapa interativo usando HTML, CSS e Bootstrap.

**Materialize**  
Template com efeito parallax e Material Design.

**Prova A1**  
Projeto de avaliação da disciplina desenvolvido com HTML e CSS.

---

**Backend:** C  
**Frontend:** HTML5, CSS3, JavaScript, pgAdmin4
**Frameworks:** Bootstrap, Materialize
